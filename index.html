How legality works

PKHeX decides. Pokekeep only does the work.

Pokekeep doesn’t change any of PKHeX’s rules. If PKHeX finds anything invalid, the result is not written.

Fix only what’s flagged

It starts with what PKHeX’s legality check points out, trash bytes in names included, and leaves PID, IVs, trainer and nickname alone when they are fine.

Regenerate if needed

If fixing isn’t enough, it rebuilds the Pokémon from a legal encounter in the same game with Auto Legality Mod, keeping species, shininess, gender, nature and moves when the game allows it.

Check again, then write

Every result goes back through PKHeX.Core before it reaches your save. Every change can be undone.

Legal here means PKHeX finds nothing invalid. It doesn’t prove how the Pokémon was obtained, or that it existed exactly like that in a real distribution.

Download

Install Pokekeep on Android or Windows

Both downloads are on the GitHub Releases page, each with its SHA-256.

Android

  1. Download the APK with the button at the top of this page, or from the Releases page.
  2. When Android asks, allow your browser or file manager to install unknown apps. Pokekeep isn’t on Google Play.
  3. Open the file and install it. It needs Android 10 or later and about 700 MB.
  4. To update, install the new APK over the old one: settings, history and bank are kept. Or add https://github.com/adriandelgadoalcalde-alt/Pokekeep as a source in Obtainium and it will tell you when there is a new version.

Windows

  1. Download the portable ZIP (119 MB) with the button at the top of this page. It’s for 64-bit Windows 10 or 11.
  2. Unzip it into a folder.
  3. Open PKHeX.exe. Nothing needs to be installed, not even .NET.

You can compare the SHA-256 of each file with the one in the release notes.

Which tool?

Pokekeep, PKHeX, Auto Legality Mod or PKSM

They are all good at different things. An honest guide:

Pokekeep

If you want to edit on your phone, or want one button that fixes only what’s wrong and checks the result with PKHeX’s own rules.

PKHeX

If you want full manual control on Windows. Pokekeep for Windows is PKHeX, so you lose nothing by switching, and nothing by staying.

PKHeX + Auto Legality Mod

If you already work from Showdown sets inside PKHeX. Pokekeep uses Auto Legality Mod under the hood when a Pokémon has to be regenerated.

PKSM

If you want to edit directly on a modded console, without moving save files around. Pokekeep works with save files on Android or Windows.

Questions

Before you download

What is Pokekeep?

Pokekeep is a free Pokémon save editor built on PKHeX. It comes as an Android app and as a portable PKHeX for Windows. Both add “Legalize automatically”, which makes a Pokémon legal by PKHeX’s rules while keeping its species and, when the game allows it, its shininess, gender, nature and moves.

Is Pokekeep safe?

The code is open source (GPL-3.0), and the repository has the scripts to build both versions from source. Every release lists the SHA-256 of its files, so you can check your download. The Android app doesn’t ask for Internet access, and it works on a copy of your save until you save.

Does it work without root?

Yes, nothing needs root. The Android app opens a save file through Android’s own file picker, and the Windows version is a portable program you unzip. All you need is the save file, and the next question explains how to get it.

How do I get my save file?

From an emulator, it’s the save file in its folder. From a console, you need a save manager on a modded console to copy it off. Pokekeep edits the file; it doesn’t talk to the console.

Which games does it support?

Every game PKHeX 26.10.18 supports, from Red and Blue to Pokémon Legends: Z-A, including Scarlet and Violet, Sword and Shield, Brilliant Diamond and Shining Pearl, Legends: Arceus and Let’s Go. The list by generation is above.

How is it different from PKHeX and PKSM?

Pokekeep for Windows is PKHeX with two more buttons (“Legalize automatically” and “Optimize stats”), a Library tab and bulk operations. The Android app is a separate app for phones that uses the same engine, PKHeX.Core. PKSM edits directly on a modded console, while Pokekeep works with save files. There is a longer comparison above.

Is it official?

No. Pokekeep is a fan-made tool and isn’t affiliated with Nintendo, Creatures Inc., GAME FREAK inc. or The Pokémon Company.

Will legal Pokémon work online?

Pokekeep makes them legal by PKHeX’s rules, which are the best public rules there are. Online services can run checks of their own, so we can’t promise anything about online play. Use it at your own risk.

Why is the APK so big?

About 700 MB, because it carries the previews and icons of every game so that it works offline.

How do I update it?

Install the new APK over the old one: settings, history and bank are kept. Or add https://github.com/adriandelgadoalcalde-alt/Pokekeep to Obtainium and it will tell you when there’s a new version.

Android says the app is unsafe or blocks it

Pokekeep isn’t on Google Play, so Android asks you to allow installs from your browser or file manager. You can compare the file’s SHA-256 with the one in the release notes.
